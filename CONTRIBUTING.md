# Contribuindo com o NowDock

Obrigado pelo interesse! O NowDock **não é open-source** ([LICENSE.md](LICENSE.md)), mas bugs, correções e ideias de todos são bem-vindos — através de **issues**.

## Como colaborar

| Quero... | Como faço |
|---|---|
| Reportar um bug | Abra uma issue do tipo **Bug** |
| Sugerir uma melhoria ou ideia | Abra uma issue do tipo **Ideia** |
| Enviar uma correção | Abra uma issue do tipo **Correção**, com a descrição e o código/patch. Se for pequeno, cole o diff direto; se for grande, anexe um arquivo `.diff` ou `.patch` (`git diff > fix.diff`) |

## Por que não aceito Pull Requests?

Para manter a titularidade do código simples e o projeto sustentável, **apenas o mantenedor abre Pull Requests**. PRs abertos por outras contas são fechados automaticamente com uma mensagem orientando a reenviar como issue. Isso não diminui sua contribuição: correções enviadas como issue são revisadas e, se aceitas, entram no código com crédito a você nas notas de release.

## Termos

Ao enviar qualquer conteúdo a este repositório, você concorda com a seção 3 (Contribuições) da [LICENSE.md](LICENSE.md): sua contribuição poderá ser incorporada ao software sem compensação.

## Reportando bugs bem

- Descreva o comportamento esperado e o observado.
- Informe: versão do macOS, player (Spotify/Música + versão), posição da Dock, se usa múltiplos monitores.
- Anexe screenshot quando ajudar.
