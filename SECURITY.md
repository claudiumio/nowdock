# Política de Segurança

## Reportando vulnerabilidades

**Não abra issues públicas para vulnerabilidades de segurança.** Envie um e-mail para **claudioorjunior@gmail.com** com:

- descrição da vulnerabilidade;
- passos para reproduzir;
- impacto estimado.

Você receberá uma resposta em até 7 dias. Se a vulnerabilidade for confirmada, será corrigida antes de qualquer divulgação pública, com crédito a você (se desejar).

## Escopo

Este projeto roda localmente no macOS e não opera serviços em nuvem. O escopo desta política cobre o código deste repositório.
